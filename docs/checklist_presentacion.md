# Checklist de presentacion

- [ ] La app abre sin internet.
- [ ] La portada indica que es MVP.
- [ ] Los datos ficticios fueron sustituidos o estan claramente etiquetados.
- [ ] Cada caso real tiene URL y ruta local.
- [ ] Cada monto fue revisado.
- [ ] Federal y CDMX estan separados.
- [ ] Las revocaciones para efectos tienen advertencia.
- [ ] La gravedad solo usa texto oficial.
- [ ] El CSV se descarga.
- [ ] El Excel se genera y abre.
- [ ] El README explica instalacion.
- [ ] La exposicion dura menos de diez minutos.
